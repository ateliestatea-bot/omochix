## 公式ページの記載（2026-10-01 確認、要旨）

- Logos：2D（default）と 2.5D（大きな用途向け）。horizontal lockup（推奨）、vertical lockup、cube 単体、wordmark 単体
- App icons：2.5D（default）、2D、3D。light / dark あり
- Avatars：2D（default）と 2.5D。light / dark。円形・正方形用
- 表記：「Cursor」と呼ぶ（「Cursor AI」「Cursor Code」ではない）

## 採用理由

- AI Tools のロゴタイルは正方形で、同じ画像を light / dark 両方で使う（object-fit: contain）
- 正方形・不透明の公式 App icon なら、プレートや余白を追加しなくてもよい
- 2.5D は公式の default
- DARK 版を選んだ理由：light / dark 両ページのタイルで比較し、LIGHT 版は light ページのカード背景（#F7F7F5 前後）とほぼ同色で輪郭が消えたため

- 1024 → 512 px の等比縮小（Lanczos）のみ
- WebP lossless 化（縮小結果とのピクセル差 0）
- 形状、色、エフェクト、余白は変更なし
