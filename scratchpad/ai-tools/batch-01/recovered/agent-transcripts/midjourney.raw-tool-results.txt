# Midjourney Video Generation Overview

## How It Works
Midjourney converts static images into dynamic videos rather than generating videos from text alone. The service is **image-to-video**, not text-to-video. Users provide an image as the first frame, optionally add a text prompt, and the system creates motion-based content.

## Video Length & Extension
Videos start at 5 seconds and can be extended up to four times, reaching a maximum of 21 seconds total. Each extension adds approximately 4 seconds and costs the same GPU time as an initial generation.

## Plan Requirements & Availability

**Plan Tiers:**
- All plans support Fast Mode video generation
- Only Pro and Mega plans enable Relax Mode (SD resolution only)
- Standard, Pro, and Mega plans can generate HD resolution (720p) in Fast Mode
- Default resolution is 480p (SD)

**Platforms:** Available on both the web interface (midjourney.com) and Discord.

## Key Features & Parameters

Motion control offers two settings: "Low Motion" produces subtle movements and still scenes (default), while "High Motion" creates larger camera and character movements. The `--raw` parameter reduces creative embellishment for more prompt-driven results.

Users can set ending frames using `--loop` for looping videos or `--end` with a different image URL. Video batch sizes range from 1-4 (default: 4), with costs scaling accordingly.

## Limitations

"Video generations are only compatible with video-specific parameters: `--motion low`, `--motion high`, `--raw`, `--loop`, `--end`, and `--bs #`." General image parameters don't carry over to video creation. External image references like Style Reference and Image Prompt aren't compatible with video generation.
