## 2. 実装(P0)
- **設計**: 公開タイトルの **キャッシュ可能な読み取り専用JSON索引**を1本(`GET /wp-json/omochix/v1/suggest-index`)。ブラウザが初回フォーカス時に1回だけ取得し、**絞り込みは100%ブラウザ内**。入力中にサーバーへのリクエスト・ログは発生しない(検索語がサーバー/ログに残らない)。
- **索引の中身**: メニューの主要6セクション・人気の検索ワード(6)・AIツール(会社名をキーワードに)・カテゴリー(ニュース/ツール用途/Prompts)・Learn 配下ページ+実践教材・Labs ツール・Prompts(120)・最新ニュース(80)。上限 420 件(本番相当で約 35〜40KB、gzip で約10KB)。**公開済み・パスワードなしの投稿のみ**。
- **サーバー負荷・濫用対策**: 15分の transient + 30秒の排他ロック(同時再構築の防止)、投稿/タームの変更で自動破棄、`Cache-Control: public, max-age=300, s-maxage=300` + ETag(CDN/ブラウザで吸収)、応答サイズ上限、認証・書き込み・個人情報なし。クエリ数は変更前と同等(5ページ実測: 同数または1少ない)。
- **フロント**(`assets/js/search-suggest.js` 8.8KB・`search-suggest.css` 1.8KB): 日本語対応の正規化(NFKC・大小・ひらがな→カタカナ)、複数語AND、前方一致優先、種類ラベル、空入力時は「メニュー+人気の検索」、最後の行は常に「『…』を全体から検索」。ARIA combobox(role=combobox/listbox/option、`aria-activedescendant`)、↑↓/Enter/Escape、IME 変換中は更新しない、タップ領域 44px、モバイルでビューポート内に収まる。CSS は初回フォーカス時に JS が追加(**描画をブロックしない**)。JS 無効/失敗時は従来のフォームがそのまま動作。
- **検索結果ページ**: 「こちらも見つかりました」(Labs ツール・Learn ページ。各3件まで、完全にエスケープ)、0件時のリンクをレジストリ(AIニュース/AIツール/AI開発/Learn/Prompts/Labs)から生成。
- **安全性**: 描画は `textContent`/DOM ノードのみ(`innerHTML` 不使用)。`<img src=x onerror=alert(1)>` を入力しても挿入されない(Chromium/WebKit で確認、ダイアログ発火 0)。サーバー側の検索語は `esc_html`/`esc_attr`、`?s=<script>…` は HTML に生で出ない(確認済み)。

## 3. QA(`tests/nav-ux/suggest.cjs`、`suggest-qa.json`)
Chromium / WebKit: フォーカス前の索引リクエスト 0、入力中の追加リクエスト 0、候補(空入力・`claude`・`プロンプト`)、ARIA、↓で選択・Escape で閉じる(入力ありは候補のみ、空はダイアログごと)、通常の Enter は `/?s=`、ヘッダーのダイアログ内でも表示、モバイル(375px・ダーク)で表示・44px、JSエラー 0、XSS 注入なし。
**未検証**: 実機のIME(iOS/Android)、スクリーンリーダー実機、本番規模での索引サイズ・LIKE検索性能、Firefox での動作(コード上は標準APIのみ)。
