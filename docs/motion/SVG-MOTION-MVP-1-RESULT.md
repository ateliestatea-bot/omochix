## 1. 実装

| # | 項目 | 実装 | ファイル |
|---|---|---|---|
| 1 | root 原点を計測できないときのフォールバック | `Frame.measure()` が `null` を返す、または失敗したとき、準備済みロゴの viewBox の中心を原点にする。値は `validateEdit` を通す（範囲外なら原点なしのまま）。フォールバックの原点は**保存しない**ので、次の訪問で計測し直す。書き出しの設定 JSON には、表示中と同じ原点が入る | `studio.js` |
| 2 | 日本語の通知 | 書き出し欄の上に見える注記（`data-svgm-origin-note`）と、読み上げ用の状態文の両方に「ロゴの中心を測れなかったため、全体の回転と拡大は画像（viewBox）の中心を基準にしています。見た目の中心と少しずれることがあります。」を出す。`data-svgm-origin-source` は `none`、`measured`、`fallback`、`provided` のいずれか | `studio.js`、`page-learn-svg-motion.php`、`inc/learn-svg-motion.php` |
| 3 | 計測中のコピーとダウンロード | 計測中は書き出しを作らない。コードの欄には「ロゴの中心を測っています。終わるとコードとファイルを用意します。」と表示し、コピー、ファイルのダウンロード、設定 JSON の保存を無効にする（`data-svgm-export="measuring"`）。計測が終わると作り直して有効に戻す | `studio.js` |
| 4 | 書き出し失敗時の古いボタン | 失敗したときは、ファイルのボタンを消し、コピーと**設定 JSON の保存**も無効にする（JSON の保存は以前は押せたまま、何も起きなかった）。作り直しを待つ 120ms の間も、前の書き出しは提供しない。無効のボタンは薄く表示する | `studio.js`、`learn-svg-motion.css` |
| 5 | 計測中に編集が変わった場合 | 以前は、計測中に別の編集を読み込むと、その編集の原点が計測されずに残っていた。計測が終わった時点で編集が変わっていれば、新しい編集を計測し直す | `studio.js` |

既存の動作への影響：編集がないとき（プリセットのみ）は計測をせず、出力も変わらない（書き出し 133 通りと既存テストで確認）。

## 2. 画面の回帰テスト（`tests/svg-motion/export-tests.js`）

| テスト | 確認すること |
|---|---|
| フォールバック（計測が `null`） | `fallback`、原点が viewBox の中心、注記と状態文に日本語の理由、インラインのコードで原点がその px に固定、コピー・2 つのファイル・JSON が有効、保存した記録に原点がない |
| フォールバック（計測が失敗） | 上と同じ |
| 次の訪問 | 再読み込みすると `measured` になり、注記が消え、原点が保存される |
| 計測中 | `measuring`、コードの欄に「測って」、コピー・ファイル・JSON がすべて無効 |
| 計測の完了 | 書き出しが戻り、すべて有効、原点は計測値（60,50） |
| EXPORT_FAILED | 失敗前に表示していたボタン 2 つが、ページから消えるか無効になっている。コピーと JSON が無効、日本語の理由。回復するとすべて有効 |
