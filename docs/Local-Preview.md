# OmochiX トップページをローカルで見る

`omochix-local-preview.html` をダウンロードしてブラウザで開く。画像、CSS、トップページ用のJSはファイルに埋め込み済み。ネット接続やWordPressの起動は不要。PC・スマホ幅のレイアウトと明暗切替を確認できる。

このHTMLに入っている記事・AIツール・プロンプトはローカルの検証用データ。投稿画像が登録されていないため承認済みの生成アートを代替表示している。公開サイトの実コンテンツは含まない。記事への遷移と検索は、この単体ファイルでは実行できない。

実際のWordPressとして動かす場合はPHP/WordPress/SQLiteの分離した検証環境でテーマを有効化する。導入条件と確認項目は [Editorial-Home-Refresh.md](Editorial-Home-Refresh.md) を参照。
