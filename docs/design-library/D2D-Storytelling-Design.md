# OmochiX Design Library — Interactive Storytelling 設計（D2-D Phase 4、実装しない）

- 作成日：2026-11-17
- 位置付け：D2-D で見送った Cinematic 3D の代わりの 4 作品目の候補。**設計だけで、コード・カタログ・試験は作っていない。**
- ID・slug（案）：`dl-web-0009` 以降の空き番号、`interactive-story`

## 1. コンセプト

架空の紙すき工房「SUKIYA（すきや）」の一年を、読み手のペースで進む物語として見せる長いページ。

- スクロールで章が進み、右側（スマホでは上側）の挿絵が段落ごとに描き変わる「スクロリーテリング」の構成。
- 加えて、読み手が「職人の目で読む／紙の目で読む」を途中で切り替えられる。切り替えると、同じ場面の本文の語り手が変わる（挿絵は同じ）。
- 章の目次からいつでも飛べる。今どこまで読んだかが常に分かる。

## 2. 既存作品との違い

| 既存作品 | 主な見せ方 | Interactive Storytelling との違い |
| --- | --- | --- |
| Minimal Editorial | 雑誌風の組版、文字の出現、ページ送り | 文字の演出ではなく、**挿絵が本文の段落に合わせて変わる**。物語の構成（章・語り手の切り替え） |
| Dark Luxury | 暗い地、作品の横スクロール（固定） | 明るい和紙の地。横スクロールは使わず、縦の段落と固定した挿絵の組み合わせ |
| 3D Interactive | WebGL で製品を回す・組み立てる | WebGL・Canvas を使わない。SVG とCSS だけ。操作の対象は製品ではなく**読み進め方** |
| Aurora Gradient | 背景の光が流れ続ける | 常に動くものは無い。段落が切り替わったときだけ動く |
| Bento SaaS・AI Workspace | 情報の整理・アプリの画面 | 読み物。数字やUIではなく、場面と語り |

新しい点は、①段落と挿絵の同期、②語り手の切り替え（分岐）、③目次と読書位置の表示。

## 3. 想定用途

- 用途：`brand-intro`・`media`・`corporate`（自治体・観光・伝統産業のブランドストーリー、NPO の活動報告、採用ページの「仕事の一日」）。
- 業種：Core の 6 用語に合うものが無いので空にする（業種の用語は Core 側の作業）。

## 4. ページ構成

1. **扉**：題名「一枚の紙ができるまで」、読む時間の目安（約 4 分）、「職人の目／紙の目」の切り替え、目次。
2. **章 1 冬・楮（こうぞ）を刈る**：段落 3 つ。挿絵：雪の畑 → 刈り取り → 束。
3. **章 2 晒す・叩く**：段落 3 つ。挿絵：川の水 → 白くなる繊維 → 木槌。
4. **章 3 漉く**：段落 4 つ。挿絵：簀桁（すけた）が水をすくう → 揺らす → 層が重なる → 紙床（しと）。
5. **章 4 乾かす・届く**：段落 3 つ。挿絵：板に貼る → 光に透かす → 手紙になる。
6. **結び**：一年の流れの小さな年表（4 章の振り返り）と、工房見学の案内（飾りのボタン。どこにも送らない）。

画面の端（PC は左、スマホは上）に、章の番号と読書位置の細い棒を常に出す。

## 5. 配色・文字

- 和紙 `#f4efe4`、藍 `#1f3a5f`、柿 `#c8553d`、墨 `#22201c`。章ごとに地の色をわずかに変える（冬は青み、夏は黄み）。
- 本文は `Hiragino Mincho ProN`・`Yu Mincho`（物語なので明朝）、見出しと UI は `Hiragino Sans`。本文 17px・行間 2.0。
- Minimal Editorial（生成りと朱、雑誌の組版）と重ならないよう、藍を主に、柿は差し色に限る。

## 6. モーション

| 動き | 方法 | 止める条件 |
| --- | --- | --- |
| 段落が画面中央に来たら挿絵が次の状態へ | IntersectionObserver で段落を検出し、SVG の部品の `transform`・`opacity`・`stroke-dashoffset` を CSS の transition で変える（0.6〜0.9 秒） | 段落が変わらない間は何も動かない |
| 章が変わると地の色が移る | `background-color` の transition 0.8 秒 | 同上 |
| 繊維・水の線が描かれる | `stroke-dashoffset`（線の描画） | 描き終えたら止まる |
| 読書位置の棒 | CSS の `animation-timeline: scroll()` が使えるブラウザーはそれで、使えないブラウザーは scroll イベント＋rAF（スクロール中だけ） | スクロールしていないとき・一時停止中は描かない |
| 語り手の切り替え | 本文の段落を差し替え（交差フェード 0.25 秒）。挿絵は変えない | 押したときだけ |

- 常に回り続ける rAF・タイマーは無い。
- 一時停止（`omx-paused`）とタブの非表示の間は、挿絵の変化を保留し、再開したときに今の段落の状態へ一度で合わせる。

## 7. 使用技術

- `html`・`css`・`js`・`svg`。WebGL・Canvas・画像ファイルは使わない（挿絵はすべてインラインの SVG で自作）。
- 外部ライブラリ・Web フォントは使わない。CSS の scroll-driven animations は対応ブラウザーでの上乗せに限り、無くても同じ内容が読める。
- カタログの値（案）：表現 `scroll`・`typography`・`transition`、スタイル `editorial`・`light`・`typography`、モーション `scroll-linked`・`line-draw`・`text-reveal`・`page-transition`、難易度 `intermediate`。**スキーマ・語彙の変更は要らない。**

## 8. スマホ対応

- 390px：挿絵を画面上部に固定（高さ 38vh）し、本文はその下を流れる。挿絵が本文を隠さないよう、段落の上に挿絵の高さ分の余白を取る。
- 目次は下から出るシート（`role="dialog"`、Esc・閉じるボタン・外側のタップで閉じる）。
- 語り手の切り替えは 44px 以上の 2 択（`radiogroup`）。
- 横向きのスマホ（高さが低い）では挿絵の固定をやめ、段落ごとに挿絵を並べる（reduced-motion と同じ表示）。

## 9. 性能の目安

| 項目 | 目安 | 根拠 |
| --- | --- | --- |
| 転送量 | 18KB 以下（gzip 後） | 既存の Web 作品は 5.6〜38.7KB。SVG の挿絵 13 状態を部品の使い回しで作る |
| JS | 4KB 以下 | IntersectionObserver と切り替えだけ |
| 長いタスク | 0 | 重い計算は無い |
| フレーム | 段落の切り替え時だけ。p5 で 60fps 以上 | transform・opacity・stroke だけを動かす |
| CLS | 0 | 挿絵の枠の大きさを先に決める |

- SVG の部品数が多くなりすぎないよう、1 つの挿絵の要素は 60 個以下を目安にし、`contain: layout paint` を付ける。

## 10. セキュリティ

- 既存の CSP・sandbox のまま（外部通信なし、`connect-src 'none'`、スクリプトはハッシュ指定）。
- 語り手の選択と読書位置はメモリーにだけ持つ（localStorage・Cookie・URL への書き込みはしない。sandbox では使えない前提）。
- 見学の案内は飾りのボタンで、フォーム・送信は無い。
- 文章・挿絵はすべて自作。実在の工房・地名・人物は使わない（架空と明記する）。

## 11. アクセシビリティ・代替表示

- 本文は普通の HTML の段落で、上から順に読める。挿絵は `aria-hidden` にし、意味は本文で伝える。
- reduced-motion・JavaScript 無効：挿絵の固定をやめ、**段落ごとにその場面の挿絵（最終状態の SVG）を並べる**。語り手の切り替えは無効にし、職人の語りだけを出す（JS 無効時は切り替えボタンを出さない）。
- Save-Data：動きは残すが、地の色の transition と線の描画を省く。
- キーボード：目次・切り替え・「次の章へ」ボタンで移動できる。章の見出しにフォーカスを移す。
