## 3. 実装の手順と検証の順番

1. 本文（13 段落 × 2 つの語り）と挿絵の SVG を作る。文章は架空の工房の物語とし、紙すきの工程（楮の刈り取り・煮る・晒す・叩く・漉く・重ねる・搾る・干す）は一般的な説明の範囲にとどめる。実在の工房・産地名・人物は出さない。
2. CSS：JS 無効・reduced-motion の並べ方（段落ごとに最終状態の挿絵）を**先に**作り、その上に固定の挿絵と切り替えを足す。
3. JS：段落の検出 → 挿絵の状態、章の地の色、目次、語りの切り替え、読書位置、一時停止の保留の順に足す。
4. カタログに `unverified` で追加し、ポスター・ループを撮る（D2-D と同じ手順：一時的な置き換え画像 → 実画像で上書き）。
5. 作品の試験：new-works（Chromium・WebKit）、操作の試験（3 ブラウザー）、isolation、firefox、axe（ライト・ダーク × 3 幅）。合格したら `verified-local`。
6. perf（この作品だけ）→ 既存の全試験 → 86 URL の回帰。

**試験の停止への備え**：D2-D で原因不明の停止が 4 件あった。今回は各試験に時間の上限（例：20 分）を付けて実行し、止まった場合は「初回の失敗」と「再実行の結果」を分けて記録する。

## 4. 操作とアクセシビリティの仕様

- 語りの切り替え：`role="radiogroup"` の 2 択（職人の目／紙の目）。矢印キーで移動。切り替えると今読んでいる段落の位置を保ち、`aria-live="polite"` で「紙の目で読んでいます」と伝える。
- 目次：見出しのボタンからシート（`role="dialog"`・`aria-modal`）を開く。章へ移るとその章の見出しにフォーカスを移す。Esc・閉じるボタン・外側のクリックで閉じ、開いたボタンにフォーカスを戻す。
- 「次の章へ」ボタンを各章の最後に置く（キーボードだけで最後まで読める）。
- 挿絵は `aria-hidden="true"`。意味は本文で伝える。
- 押せる部分は 44px 以上。本文 17px・行間 2.0。文字と地のコントラストは 4.5:1 以上（章ごとの地の色すべてで測る）。

## 5. 代替表示

| 条件 | 表示 |
| --- | --- |
| JavaScript 無効 | 挿絵の固定をやめ、段落ごとに最終状態の挿絵を並べる。職人の語りだけ。切り替え・目次のシートは出さない（目次はページ内リンクの一覧として表示） |
| reduced-motion | JS 無効と同じ並べ方。語りの切り替えと目次は使える（切り替えは即時） |
| Save-Data | 固定の挿絵は使うが、地の色の transition と線の描画を省き、状態は即時に切り替える |
| 横向きのスマホ（高さ 500px 未満） | reduced-motion と同じ並べ方 |
| 一時停止・タブ非表示・画面外 | 状態を切り替えない。再開したら今の段落の状態に一度で合わせる |

## 6. 性能の目安

転送 18KB 以下（gzip）、JS 4KB 以下、長いタスク 0、CLS 0、fps p5 60 以上。常に回る rAF・タイマーは無い（スクロール中の読書位置だけ）。SVG の 1 状態あたりの要素は 60 個以下、挿絵の枠に `contain: layout paint`。

## 7. リスクと対策

| リスク | 影響 | 対策 |
| --- | --- | --- |
| 既存のスクロール作品（6 件）との重なり | 新しさが伝わらない | 「挿絵の同期」と「語りの切り替え」は削らない。配色は藍と和紙で、Minimal Editorial（生成りと朱）・Dark Luxury（黒と金）と分ける |
| 詳細ページの埋め込み（iframe）の中でのスクロール | 固定の挿絵・段落の検出が iframe のスクロールで正しく動くか | iframe 内の文書のスクロールで動くよう、IntersectionObserver の root は既定（その文書のビューポート）にする。PC・タブレット・スマホの 3 つのプレビュー幅で試験する |
| CSS transition が一時停止で止まらない | 一時停止中に挿絵が動く | §1 のとおり、一時停止・非表示中はクラスを切り替えない。試験で「一時停止中は挿絵の状態が変わらない」を確かめる |
| SVG の作り込みの量 | 制作時間がかかる、転送量が増える | 部品（山・川・簀桁・紙）を使い回し、状態はクラスで位置・不透明度だけを変える |
| 語りの切り替え時の位置ずれ | 読んでいた場所を見失う | 段落の高さを 2 つの語りで近い長さにし、切り替え前後で同じ段落を画面の同じ位置に保つ |
| 紙すきの工程の正確さ | 誤った説明 | 一般的な工程の説明にとどめ、数値・産地・歴史の断定は書かない。架空の工房の物語と明記する |
| 工房名の商標 | 公開後の名称変更 | 公開前に商標の登録を確認する（未解決） |
| 試験の停止（原因不明） | 検証に時間がかかる、結果の解釈が難しい | 時間の上限付きで実行し、初回と再実行を分けて記録する |
| JS 無効時の長さ | 13 枚の挿絵が並び、ページが長くなる | 挿絵の高さを JS 無効時は小さく（最大 240px）する |
