## 1. 改善内容

### A. カテゴリーラベル
- 「Web デザイン」「動画モーション」を、プレビューの上から本文の先頭行へ移した。
- 紫の小さなラベルにし、その後ろに作品の情報を続けた（B・D）。
- プレビューの上には、再生ボタン以外に何も載らない。

### B. 再生・一時停止ボタン
- 大きさを 40px → 34px にした。半透明の地に細い白線の縁を付けた。
- 当たり判定は `::before` で外側へ 5px 広げ、44px を確保した。円の少し外をタップしても押せることを試験で確認した。
- 見え方：
  - PC では普段は不透明度 0.8 で、カードにホバーやフォーカスがあると濃くなる。
  - タッチ端末（`hover: none`）では常に 0.95。
- フォーカスリング・`aria-pressed`・読み上げのラベルは従来どおり。

### C. カードレイアウト
- 列数は `minmax(max(340px, 半分), 1fr)` で決め、最大 2 列にした。

  | 画面幅 | 列数 |
  | --- | --- |
  | PC（1440） | 2 列 |
  | タブレット（834） | 2 列（カード幅 約 380px） |
  | 740px 未満 | 1 列 |
  | スマホ（390） | 1 列 |

- プレビューは 16:10 のまま。
  - Web 作品のポスターは 1280×800（16:10）なので、切れない。
  - 動画作品は、縦型（9:16）・横型（16:9）とも全体を表示（contain）した。余白には、同じポスターをぼかした背景を敷いた。以前は横型が左右、縦型の文字がラベルの下で一部隠れていた。
- 自動再生の条件を「カードの半分が画面内」から「プレビューの半分が画面内」に変えた（`design-library.js`）。2 列でカードが縦に長くなり、PC の最初の画面で自動再生が始まらなくなったためで、以前と同じく最初の画面で 2 本まで再生される。同時再生の上限 2 本、reduced-motion・Save-Data・メモリの少ない端末で自動再生しないこと、タブが非表示のとき止めることは変えていない。

### D. 動画作品の情報
- カタログの値から、本文先頭の 1 行を作る（`omochix_design_card_facts()`）。

  | 種類 | 表示 | 例 |
  | --- | --- | --- |
  | 動画 | 長さ・アスペクト比・向き | 「動画モーション・6 秒・9:16 縦型」「動画モーション・8 秒・16:9 横型」 |
  | Web | 「ライブデモ」と、特徴になる描画技術（WebGL・Canvas） | 「Web デザイン・ライブデモ・WebGL」 |

- モーションの種類は、この行には入れずタグに残した（同じ情報を 2 回出さない）。

### E. 情報の整理
- **作品名**：19px → 20px、行間 1.35。
- **説明文**：2 行で省略（`line-clamp`）。全文は詳細ページにある。
- **タグ**：用途 2 件と表現 2 件まで表示し、残りは「+N」にした（読み上げでは「ほか N 件（詳細ページに記載）」）。フィルターとキーワード検索は従来どおりすべての値を対象にする（例：Aurora Gradient は「ポインター」のタグを表示しないが、`motion_type=pointer` で見つかる）。
- **操作**：
  - 「詳細を見る」を唯一の主ボタン（紫）にした。
  - 「デモを開く」は ↗ 付きの文字リンクに下げた（新しいタブで開く。読み上げ用の注記はそのまま）。
  - タブ順は「作品名 → 詳細を見る → デモを開く」。
- フィルター・検索・件数表示・URL の同期は変えていない。並べ替えの操作は元々なく、一覧はカタログの順に並ぶ（順序は unit 試験と最終監査で確認）。

### 3.2 D2-C で確認した項目
- **レイアウト**（Chromium・WebKit・Firefox）：
  - 1440px で 2 列、834px で 2 列（各カード 300px 以上）、390px で 1 列。
  - トップ・Web・動画の 3 ページとも横スクロールは無い。
- **表示**：ラベルがプレビューの下にあり、何も覆っていない。プレビューは切れない。説明文は 2 行以内、タグは 5 個以内、主ボタンは 1 つ。
- **キーボード**：再生ボタンにフォーカスの輪が出て、`aria-pressed` が切り替わる。カード内のタブ順は作品名 → 詳細 → デモ。WebKit は Option+Tab で確認した。
- **axe**（WCAG 2.2 A/AA、ライト・ダーク、1440・390px）：serious・critical は 0。
- **reduced-motion・Save-Data**：自動再生しない。再生ボタンで 1 本だけ再生される。
- **JS 無効**：ラベル 8 件が表示され、再生ボタンは出ない。横スクロールも無い。サーバー側のフィルターも動く。
- **CSP・sandbox**：デモ本体・ランタイム・隔離のコードに差分は無い。isolation 88 項目と firefox の CSP・cookie の項目がすべて合格した。
- **デモの再生・一時停止**：preview 84 項目と new-works 74 項目が合格した。
- **性能**：
  - 一覧の初回転送量は 455.7 → 456.8 KB（ループ 2 本を含む）。reduced-motion では 173 KB で、動画は読み込まない。
  - CLS は 0。

### 3.4 最終監査での追加確認（2026-11-17）

- **縦型動画**：PC・タブレット・スマホ（Chromium・WebKit）で、画面全体がプレビューの枠内に収まる。再生ボタンは映像と重ならず、プレビューの上に載るほかの要素も無い。
- **ぼかし背景の負荷**：Chromium・CPU 4 倍、2 本再生中の比較。差は計測できなかった。

  | 条件 | フレーム間隔 p95 | 平均 |
  | --- | --- | --- |
  | ぼかしあり | 34.2 ms | 29.1〜29.4 ms |
  | ぼかしなし | 34.2 ms | 28.9 ms |

  ぼかしは静止画にかけているだけで、動かさない。
- **同時再生**：縦に長い画面で 8 作品すべての再生ボタンを押しても、同時に再生されるのは最大 2 本。
- **キーワード・フィルター**：「オーロラ」で Aurora Gradient だけ、動画＋ロゴで Logo Reveal Short だけ。JS 無効でもサーバー側のフィルターと、動画詳細の `<video controls>` が使える。

## 5. 未検証・残る課題

- **Firefox**：列数・ラベル・ボタンの大きさまで。説明文の行数、タグ数、タブ順、axe は Chromium と WebKit だけで確認した。
- **実機**：iOS Safari・Android Chrome の実機で、タップのしやすさと 2 列・1 列の切り替わりは確認していない。
- **Save-Data と端末メモリ**：試験上の偽装だけ。
- **説明文の 2 行省略**：要約が長い作品では文の途中で切れる（全文は詳細ページにある）。
- **作品が増えたとき**：タグを「+N」にまとめたため、一覧で見えるタグが減った。並べ替えやタグの優先順位を作品ごとに調整するかは、作品が増えた段階で判断したい。
- **D2-B から引き継ぐ未確認事項**：本番環境（LiteSpeed・キャッシュ）、永続オブジェクトキャッシュ、実際の Slim SEO との連携、本番の Learn ページ。
