### 7.9 本番のキャッシュ構成と検索候補 API のヘッダー（2026-11-17）

**本番の構成**（運営者が管理画面で確認。設定変更・キャッシュ削除はしていない）

| 項目 | 状態 |
|---|---|
| ロリポップ！アクセラレータ | ON・初期設定モード（静的ファイル限定モードは未選択） |
| LiteSpeed Cache（プラグイン） | パブリック・プライベート・オブジェクト・ブラウザーのキャッシュはすべて OFF |
| QUIC.cloud CDN | 有効化前 |

`x-cache` の提供元、`no-store` と 503 の扱い、保持時間は**未確定**のまま。アクセラレータが ON で、LiteSpeed Cache のキャッシュがすべて OFF なので、HIT はアクセラレータによる可能性があるが、断定しない。

**検索候補 API**（コードから特定）：`/wp-json/omochix/v1/suggest-index`（`inc/search-suggest.php` の `register_rest_route('omochix/v1', '/suggest-index')`。URL は `rest_url()` で作り、`assets/js/search-suggest.js` が検索欄に初めてフォーカスしたときに 1 回だけ取得し、そのページの間はメモリに持つ）。本番 1.29.0 にはまだない（404）。

現在の実装のヘッダー（ローカル 8940 で取得）：

| 応答 | ヘッダー |
|---|---|
| 通常（200） | `Cache-Control: public, max-age=300, s-maxage=300`、`ETag: "<v>"`、`X-Robots-Tag: noindex`、`Vary: Origin`。`If-None-Match` を付けても 304 にならず 200（再検証はしていない） |
| 再構築中（503） | `Cache-Control: no-store`、`Retry-After: 5`、ETag なし |

WordPress の中の索引のキャッシュ：transient `omochix_suggest_index_v2`（15 分）と再構築のロック（30 秒）。投稿・タームの保存や削除で transient を消すので、次の取得で作り直す。**HTTP のヘッダーとは独立**している。

**2 つの案の比較**

| | A：今のヘッダーのまま | B：API だけ `no-store` |
|---|---|---|
| 200 のヘッダー | `public, max-age=300, s-maxage=300` + ETag | `no-store`（ETag は外す。304 に対応していないので効果がない） |
| 非公開にした題名が残る時間 | ブラウザに最大 300 秒、アクセラレータが保存するならその保持時間（未確定）、開いているタブ | アクセラレータが `no-store` を守れば、開いているタブだけ。守らない場合は A と同じく未確定 |
| 503 | `no-store`（変わらない） | 同じ |
| 負荷 | キャッシュに当たれば PHP は動かない | 取得のたびに WordPress の REST が動く。ただし内容は transient から返すだけ（DB の読み取り 1 回程度。オブジェクトキャッシュは OFF）。作り直しは 15 分に 1 回か保存の後だけで、ロックで同時には 1 回 |
| 取得の回数 | ページを開くごとではなく、検索欄に初めてフォーカスしたときだけ 1 回 | 同じ（ブラウザに残らないので、ページを移るたびに 1 回） |
| 応答の大きさ | ローカルで約 4KB。本番は件数が多いので大きくなる（ツール・プロンプト・記事などの上限まで） | 同じ |
| 内部の索引キャッシュ | 維持 | **維持**（変わるのは応答のヘッダーだけ） |
| サイト全体・REST 全体のキャッシュ | 変えない | 変えない |

**推奨：B（API だけ `no-store`）**。保持時間も `no-store` の扱いも分からないキャッシュに頼らず、非公開にした題名を保存の直後から出さないことを優先する。増える負荷は、検索欄を使った人の 1 回の REST（transient の読み取り）だけ。アクセラレータが `no-store` を守るかは、反映後に読み取りで確かめる（2 回取得して `Cache-Control: no-store` で、2 回目に `x-cache: HIT` が付かないこと）。HIT が付く場合は、アクセラレータでこの URL だけを除外する方法を運営者が確認する（ロリポップの回答では未確定）。

**B に必要な最小の差分**（2026-11-17 に `c711635` で実施。下の 7.10）

1. `wp-theme/omochix-theme/inc/search-suggest.php`

   - 11 行目のコメント（「Cache-Control public for 5 minutes (+ ETag)」）を合わせて直す。
