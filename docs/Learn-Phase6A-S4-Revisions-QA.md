# Learn 実践教材 メタのリビジョン — Local 検証手順（Phase 6A-S4）

作成日：2026年10月25日
対象：Core Plugin `feature/learn-phase6a-s4`（`register_post_meta` の `revisions_enabled`、インポーター更新時のリビジョン記録）
前提：WordPress 6.4 以降（プラグイン要件は 6.8 以上）。本番では行わない。Local（omochix-learn-v2）で、テスト用の下書き教材 1 件を使う。

## 期待する動作（第一案）

- 実践教材を保存するたびにリビジョンが作られ、その中に 25 個のメタ（概要・プロンプト・手順・関連 ID・検証日など）も入る。
- リビジョン画面の「この版に戻す」で、本文だけでなくメタも戻る。
- 何も変えずに保存した場合はリビジョンが増えない。
- JSON インポートの更新は、実行前と実行後の状態がそれぞれリビジョンとして残る（新規作成は通常の初回保存と同じ）。

第一案が下記のいずれかで期待どおりでない場合は第二案（保存前スナップショットを hidden meta `_omochix_practice_history` に最新 10 件積み、パネルから復元）に切り替える。

## 準備

1. Local で omochix-learn-v2 を起動し、`wp-content/plugins/omochix-core` を本ブランチへ向ける（終わったら元に戻す）。
2. 管理画面 → Learn 実践教材 → 新規追加。タイトル「リビジョン検証」、概要パネルの説明と難易度・所要時間を入れ、**下書き保存**する。投稿 ID を控える。
3. リビジョン数の確認は、投稿編集画面の「リビジョン」パネル、または Local の PHP で次を実行する。

```bash
"$PHP" -c "$INI" -r 'define("WP_USE_THEMES",false); require "/Users/omochi/Local Sites/omochix-learn-v2/app/public/wp-load.php"; $id=(int)$argv[1]; foreach (wp_get_post_revisions($id, ["order"=>"ASC"]) as $r) { echo $r->ID, " ", $r->post_modified, " outcome=", json_encode(get_post_meta($r->ID, "practice_outcome", true), JSON_UNESCAPED_UNICODE), " minutes=", json_encode(get_post_meta($r->ID, "practice_minutes", true)), "\n"; }' -- <投稿ID>
```

（`$PHP` と `$INI` は Local の PHP バイナリと php.ini。）

## 検証 1：クラシック meta box の保存（ブロックエディタ内の meta box）

| 手順 | 期待 |
|---|---|
| 1-1 完成イメージ（practice_outcome）に「A」と入れて下書き保存 | リビジョンが 1 つ増え、その `practice_outcome` が「A」 |
| 1-2 「B」に変えて下書き保存 | リビジョンがもう 1 つ増え、最新が「B」、ひとつ前が「A」 |
| 1-3 何も変えずに下書き保存 | リビジョン数が増えない |
| 1-4 リビジョン画面で「A」の版を「この版に戻す」 | 編集画面の完成イメージが「A」に戻る（`get_post_meta` も「A」） |
| 1-5 所要時間を 10 → 20 に変えて保存し、戻す | 分も戻る（integer のメタも対象） |

## 検証 2：ブロックエディタ側の保存（REST）

| 手順 | 期待 |
|---|---|
| 2-1 本文（エディタ）を変更して下書き保存（meta box は触らない） | リビジョンが増え、そのリビジョンのメタは現在値と同じ（古い値に戻っていない） |
| 2-2 本文と完成イメージを同時に変えて保存 | 1 回の保存でリビジョンは 1 つだけ増え、本文とメタの両方が新しい値 |

2-2 でリビジョンのメタが古い値のままなら、REST 保存と meta box 保存の 2 リクエスト間でリビジョンが先に作られている。この場合は第二案へ。

## 検証 3：JSON インポートの更新

| 手順 | 期待 |
|---|---|
| 3-1 検証用教材を JSON エクスポートし、`practice_outcome` を「C」に編集して dry-run → 反映 | リビジョンが 2 つ増える：反映前（「B」または直前の値）と反映後（「C」） |
| 3-2 同じファイルをもう一度反映（unchanged） | リビジョンは増えない |
| 3-3 リビジョン画面で反映前の版に戻す | 「C」が元の値に戻る |

## 検証 4：既存教材への影響

| 手順 | 期待 |
|---|---|
| 4-1 既存の公開中教材（Local の seed）を開いて何も変えずに閉じる | リビジョン・メタに変化なし |
| 4-2 公開中教材を一覧のクイック編集で所要時間だけ変える | リビジョンが増え、メタが入っている。公開状態は変わらない |

## 検証 5：ガードとの併用（S3）

| 手順 | 期待 |
|---|---|
| 5-1 必須が欠けた下書きで「公開」 | ブロックエディタにエラー「公開できません。必須項目が未入力です：…」が出て、下書きのまま。リビジョンは増えない |
| 5-2 必須を埋めて下書き保存 → 公開 | 公開される |

## 記録

結果（OK / NG と気付き）を `docs/learn-v2-qa/` の既存の形式に合わせて残し、NG があれば第二案に進む判断を報告する。検証後は Local のプラグイン symlink を元に戻す。
