# Code Studio:iPhone Safari・VoiceOver 検証手順(運営者向け)

**すべて実機操作が必要。Claude は実行できない。結果が記入されるまで「未検証」とし、PASS として扱わない。**

## 0. 事前準備(運営者の判断が要るもの)

| # | 内容 | 状態 |
| --- | --- | --- |
| 0-1 | iPhone から QA サイト(`omochix-labs-qa.local`)を開く経路を用意する。候補:Local の Live Link、または以前使った tailnet 内だけの Tailscale Serve。**どちらも外部に公開する操作なので、別途承認が要る** | 未承認 |
| 0-2 | QA の Code Studio が公開状態であること(QA の catalog のコピーだけ。2026-11-20 時点で公開状態) | 済 |
| 0-3 | 記録する端末情報:iPhone の機種、iOS の版、Safari、文字サイズの設定 | 未 |

http のままだと「コピー」は代わりの方法で動く(本番は https)。経路が https なら本番と同じ条件になる。
