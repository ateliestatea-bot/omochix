# OmochiX トップページ刷新 / 1.14.0

2026-10-08。ブランチ `feature/editorial-home-refresh`。基点 `1928135`。
ローカル実装・検証完了。本番適用・GitHubへのpush・mainへのマージは未実施。

## 変更内容

余白を生かした検索中心の余白を広く取ったヒーロー、カテゴリー別SVGアイコン、注目記事、最新ニュース、Prompts/Learn、AIツール、紹介、シックなフッターに再構成。スマホの短い2行見出しと、PCの文章・画像を横に並べた注目記事で、最初に見る順序を明確にした。
PCでは左ナビゲーション、1080px以下は既存モバイルメニューを利用。紫はアクセントとし、既存テーマ切替に合わせて明暗両モードに対応する。
おもちには既存の `omochi-hero.webp` を使用。フッターにはおもちを置かず、既存の公式X・Instagram・TikTok・YouTubeリンクとロゴを再利用する。

対象はトップページ。記事、検索結果、ツール詳細などのテンプレートやそのヘッダー・フッターデザインは今回の変更対象外。
コミュニティと動画は公開ページがあればリンク、なければ準備中。マーケットや会員・保存機能は未実装。

## データとの接続

| 表示 | データ・動作 |
| --- | --- |
| 注目記事 | 公開済み・パスワードなしの先頭固定記事の最新1件。なければ `ai-news` の最新記事 |
| 最新ニュース | `ai-news` の公開済み最新3件。注目記事との重複を除外 |
| AIツール | 既存の有効ツール判定を使用。おすすめ最大3件を表示順で並べ、足りなければ有効な公開ツールで補完 |
| Prompts | 本文がある最新の公開プロンプト。コピー内容は `prompt_body` をそのまま保持 |
| カテゴリー | 投稿一覧設定・既存CPTアーカイブ・既存カテゴリ・公開済みLearnへのURLを使用 |
| 画像 | WordPressのアイキャッチ。未登録の記事は画像枠を出さず見出し中心の表示 |
| ツールロゴ | `tool_logo` 添付ID/URL → アイキャッチ → 頭文字 |
| 検索 | 既存WordPressのGET検索 `s` を使用 |
| フッター | 既存公式SNS定義、公開済みの案内・法務ページを使用 |

投稿・メタ・タクソノミー・パーマリンク・REST API・プラグインに変更なし。DB移行なし。
自動投稿システムが登録する記事、アイキャッチ、カテゴリーを通常の公開条件に従って表示する。外部自動投稿システムとの実接続試験は今回未実施。
架空の記事・ツールは実装に含めない。データがない場合は空状態を表示する。

## 導入手順

1. ブランチの差分と本ドキュメントをレビューする。リポジトリのAGENTS.mdに従い、pushとmainマージはそれぞれ明示許可を得る。
2. 本番で稼働中のテーマ一式をバックアップする。本番の稼働SHAと基点との差分を確認し、このブランチに含まれない修正を上書きしない。
3. ステージングにテーマ一式を反映。DBや投稿の移行・変更は不要。ページキャッシュを更新する。
4. 実コンテンツでアイキャッチのトリミング、長い日本語タイトル、ツールロゴ、投稿一覧設定、カテゴリーと公開ページ、公式SNSの遷移先を確認する。
5. スマホ実機で検索・メニュー・テーマ切替・コピーを確認。記事・検索・ツール・Learn・Promptsの既存ページを回帰確認し、canonical/OGP/構造化データを確認する。
6. ステージング確認後、本番反映の承認を得る。既存デプロイRunbookに従ってテーマを反映する。
7. 問題時はバックアップした稼働テーマに戻してキャッシュ更新。DB変更がないため、DBロールバックは不要。
