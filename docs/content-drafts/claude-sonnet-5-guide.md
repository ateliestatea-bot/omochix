Anthropicは2026年6月30日、新モデル「Claude Sonnet 5」を発表し、同日から提供を開始しました。

Claude Sonnet 5は、会話の回答品質だけでなく、計画を立て、ブラウザーやターミナルなどのツールを使い、複数工程の仕事を進める能力を重視したモデルです。Anthropicは、従来より大きく高価なモデルが必要だった水準の自律的な処理を、Sonnetクラスで実行できるようにすることを狙っています。

この記事では、Claude Sonnet 5で何が変わったのか、仕事やAI開発でどのように捉えればよいのかを、Anthropicの公式情報に基づいて整理します。

## 今回発表されたClaude Sonnet 5とは？

Claude Sonnet 5は、Anthropicが「最もエージェント的（計画し、ツールを使いながら複数工程を進める性質が強い）なSonnetモデル」と説明するAIモデルです。正式発表と提供開始はいずれも2026年6月30日です。

Sonnetは、Claudeのモデル群で性能と費用のバランスを担う位置づけです。Anthropicによると、Sonnet 5では前世代のSonnet 4.6から、推論、ツール利用、コーディング、ナレッジワークなど、エージェント型の処理に関係する能力が改善されました。

提供範囲も広く、ClaudeではFreeとProのデフォルトモデルとなり、Max、Team、Enterpriseでも利用できます。開発者向けにはClaude CodeとClaude Platformで提供され、Claude APIでは`claude-sonnet-5`というモデルIDで利用できます。

日本については、Anthropic公式の対応地域一覧で、Claude.aiと商用APIの両方に日本が掲載されています。ただし、実際に使える機能や上限はプラン、組織設定、利用ティアなどで異なる可能性があります。

## Claude Sonnet 5で何が変わった？

公式発表で中心となっているのは、「質問に答える」ことから「仕事を完了まで進める」ことへの強化です。

Claude Sonnet 5は、複数工程の計画を立て、ブラウザーやターミナルといったツールを使いながら処理を継続することを想定しています。Anthropicは、前世代と比べて推論、ツール利用、コーディング、ナレッジワークに改善があると説明しています。

また、利用者はeffortレベル（AIが回答までに使う処理量の設定）を選び、処理に使う計算量と費用のバランスを調整できます。中程度のeffortでは費用効率を重視し、高いeffortでは難しい仕事へより多くの処理を割り当てるという使い方です。

安全面では、Anthropicの事前評価で、Sonnet 4.6より望ましくない挙動が全体として少なく、悪意ある依頼の拒否やプロンプトインジェクション（外部の文章などに紛れた指示でAIを意図しない操作へ誘導する攻撃）への抵抗にも改善が見られたと報告されています。一方で、評価は安全性や正確性の保証ではありません。実運用では、権限を限定し、操作履歴と結果を人が確認する設計が必要です。

2026年8月20日時点のAPI価格は、100万トークンあたり入力2ドル、出力10ドルです。Anthropic公式発表では、この導入価格は2026年8月31日までで、その後は入力3ドル、出力15ドルへ移行すると案内されています。公開日が8月31日以降になる場合は、公開直前に公式発表とPricingで実価格を再確認してください。

Anthropicは、Sonnet 5で新しいTokenizer（文章をAIが処理する単位へ分割する仕組み）を採用したため、同じ入力でもSonnet 4.6と比べておよそ1.0〜1.35倍のトークンになる場合があると説明しています。API利用では単価だけでなく、実際に消費するトークン数も含めて移行前後の費用を確認する必要があります。

## コーディング・AI開発では何が変わる？

Claude Sonnet 5は、単発のコード生成よりも、調査から実装、検証までをつなぐ複数工程の開発での利用が想定されています。

たとえば、不具合修正では、関連コードを調べ、再現方法を作り、修正を実装し、テスト結果を確認するまでに複数の判断が必要です。Sonnet 5は、計画を保ちながらブラウザーやターミナルを使えることを特徴としており、Claude Codeのような環境で一連の作業を進める用途と相性があります。

仕事で考えられる活用例は次のとおりです。

- 既存コードベースの調査と変更箇所の特定
- 複数ファイルにまたがる実装
- テストの作成と実行結果の確認
- 不具合の再現、原因調査、修正案の検証
- 技術文書や変更内容の整理
- ブラウザーや外部ツールを含む開発手順の自動化

ただし、Claudeが長く処理を続けられることと、変更内容が常に正しいことは別です。コードレビュー、テスト、権限管理、機密情報の扱い、デプロイ前の承認は引き続き必要です。特に本番環境へ影響する操作は、AIが単独で確定しないワークフローにするべきです。

APIではモデルID`claude-sonnet-5`が案内されています。レート制限は利用ティアなどで異なり、AnthropicはClaude Consoleで現在の上限を確認するよう案内しています。記事作成時点で全利用者に共通する具体的な上限値は確認できないため、導入前に各アカウントでの確認が必要です。

## AIエージェントとの関係

AIエージェントは、利用者の指示を受けて計画を立て、必要なツールを選び、複数の工程を進める仕組みです。Claude Sonnet 5は、この「計画・ツール利用・継続実行」を主要な改善点にしています。

従来のチャットでは、人が工程ごとに質問し、結果を次の指示へつなぐ場面が多くありました。エージェント型の利用では、目標と制約を渡したうえで、AIが調査、操作、確認を繰り返します。開発だけでなく、社内情報の整理、調査、定型業務などへの応用も考えられます。

一方、エージェントへ広い権限を与えるほど、誤操作や意図しないデータ利用の影響も大きくなります。実務では、読み取り専用から始める、操作範囲を限定する、重要な段階に人の承認を入れる、ログを保存するといった安全設計が欠かせません。

Sonnet 5の発表は、エージェントが人の確認を不要にするという意味ではありません。AIが担う実行範囲を広げつつ、人が目標、権限、評価基準、最終判断を管理する方向への更新と捉えるのが適切です。

## どんな人に向いている？

Claude Sonnet 5は、次のような利用者にとって検討しやすいモデルです。

- Claudeを日常的な文章作成や調査に利用する人
- Claude Codeで複数工程の開発を進めたい開発者
- APIでツール利用を含むAI機能を構築するチーム
- 高い処理能力と運用費用のバランスを調整したい組織
- AIエージェントを小さな業務から試したい担当者

FreeとProではデフォルトモデルとして提供されるため、一般利用者も特別なモデル選択なしで触れる機会があります。Max、Team、Enterpriseでも利用できますが、具体的な利用量や組織設定は契約内容によって異なります。

API利用者は、2026年8月31日までの入力100万トークン2ドル・出力100万トークン10ドルという導入価格と、その後に案内されている入力3ドル・出力15ドル、新しいTokenizerによるトークン数の変化を含めて費用を試算する必要があります。大量処理では、少数の実データで品質、速度、トークン消費量を測り、権限・ログ・承認手順も確認してから拡大するのが安全です。公開日が8月31日以降になる場合は、公式発表とPricingを再確認してください。

## ChatGPTなど他のAIとはどう使い分ける？

> **OmochiX編集部の見解**
>
> Claude Sonnet 5とChatGPTなどの使い分けは、モデル名だけで性能の優劣を決めるのではなく、作業環境、必要なツール、費用、確認方法から判断することが重要です。

Claude Codeを中心に既存コードの調査からテストまで進めたい場合や、Claude Platformでエージェント機能を構築する場合は、Sonnet 5が有力な選択肢になります。一方、別のAIサービスが持つ検索、画像、音声、社内ツール連携などが業務に必要であれば、その製品全体の機能も比較する必要があります。

また、同じコーディング作業でも、新規開発、既存システムの修正、大量の定型処理では評価基準が異なります。代表的なタスクを用意し、正確性、完了率、所要時間、費用、人が修正した量を比べると、実務に合うモデルを判断しやすくなります。

Anthropic公式発表だけでは、他社モデルとの包括的な優劣は確認できません。そのため、本稿ではClaude Sonnet 5が常に他のAIより優れているとは評価しません。

## まとめ

Claude Sonnet 5は、2026年6月30日に発表・提供開始された、エージェント型の仕事を重視するSonnetモデルです。

要点は次のとおりです。

- 計画、ツール利用、コーディング、ナレッジワークを改善
- Claudeの全プラン、Claude Code、Claude Platformで提供
- APIでは`claude-sonnet-5`として利用可能
- effortレベルで能力、速度、費用のバランスを調整可能
- APIの導入価格は入力100万トークン2ドル、出力100万トークン10ドル（2026年8月31日まで。その後は入力3ドル、出力15ドルと案内）
- Claude.aiと商用APIの公式対応地域に日本を掲載

Claude Sonnet 5は、AIが回答するだけでなく、複数工程の仕事を進める方向を示すアップデートです。ただし、実務導入ではモデルの自律性だけでなく、権限管理、レビュー、テスト、費用計測をセットで設計する必要があります。

OmochiXでは今後、Claude Sonnet 5とClaude Codeを使った開発フローや、実際の業務での使い分けも検証していきます。
