# Social brand SVGs

Source: https://github.com/simple-icons/simple-icons/tree/develop/icons
Retrieved: 2026-10-09 (JST).

X, Instagram, TikTok and YouTube SVG paths are vendored from Simple Icons (CC0; included LICENSE.md). Only metadata/title removal and accessible decorative attributes plus `fill="currentColor"` were applied; the brand paths were not redrawn. Icons are rendered from a fixed allowlist and load without an external CDN.
